# solverone-dados

Arquivos master da plataforma SolverONE, publicados pelo RootifyONE.
Não edite à mão: mude no RootifyONE e publique de novo.

| Arquivo | O que é |
|---|---|
| apps.json | catálogo dos apps e versão mínima de cada um |
| planos.json | planos de usuário |
| servicos/<app>.json | serviços de cada app e os planos que podem usar |
| termos.json | termos e políticas publicados (PT/EN) |
| recados.json | avisos para a caixa de recados dos apps |
| anuncios.json | anúncios da faixa e do pop-up |
| ajuda.json | artigos de ajuda do Assist ONE |
| versoes/<app>.json | o que cada versão de cada app trouxe |

Nenhum dado pessoal mora aqui: este repositório é público.
